# HACKER LAB

プログラミングやセキュリティを知らない初心者が、**架空のサイバー事件を解決しながら**、自分や他人を守る知識を身につける学習アプリです。
ユーザーは調査担当者として、メール・通信記録・設定・コードから証拠を集め、原因を推理し、対策を実行して結果を検証します。

## 起動方法

ビルドは不要です（HTML / CSS / JavaScript のみ、外部ライブラリなし）。

- `index.html` をブラウザで直接開く、または
- 静的サーバーで配信する：`npx http-server .` → 表示された URL を開く

進捗はブラウザの `localStorage`（キー `hackerlab.progress`）に保存されます。

## 機能

| 機能 | 内容 |
|---|---|
| 事件ファイル | 全6章・30事件。依頼 → 講義 → 資料調査 → 証拠保存 → 原因特定 → コード検証 → 被害対応 → 調査レポート |
| 講義 | 30事件すべてに専用の講義（原理 / 仕組み・コード / 事件に使う / 理解度チェック）。途中位置とチェック結果を保存 |
| コード演習 | 初心者向け JavaScript（`const` `true/false` `if/else` `===` `&&` `\|\|` `!` `console.log` など）。入力ごとの期待結果と実際の結果を表示 |
| 解決条件 | 必要な証拠・講義チェック・原因と根拠・コードテスト・被害対応・レポートがすべてそろって初めて解決認定 |
| 銀行事件（LEVEL 30） | 送金台帳、停止 / 凍結 / 返還（演習上の仮定）/ 未解決の区別、銀行全体の防御シナリオ検証 |
| NOVA | 調査支援の**模擬AI（定型応答）**。実際の AI API には接続していません |
| 基礎実践 | 通信・変数・条件分岐・認証・認可の小さな演習（動画とは独立） |
| 動画で学ぶ | 実在を確認した YouTube 講義の分類・検索・視聴（埋め込み＋「YouTubeで開く」） |
| 単語検索 | 日本語・英語・読みがなで引ける用語辞典 |
| 進捗 | レベル解放、体験モード（上位事件も最後まで試せる・正式認定は順番）、検索と絞り込み、事件単位のやり直し、旧形式からの移行で解決記録を保持 |

## 安全への配慮

- 登場する組織・人物・URL・口座・金額はすべて架空です。URL とメールアドレスには予約済みの `.example` ドメインだけを使っています（自動テストで確認）。
- コード演習は `js/engine/minijs.js` の**自作の制限付きインタプリタ**で判定します。`eval` / `Function` は使わず、使える文法も限定しているため、外部通信や OS コマンドには到達できません。
- `index.html` の Content-Security-Policy で、外部への通信（`connect-src 'none'`）と外部スクリプトを禁止しています。外部から読み込むのは YouTube の埋め込み（`youtube-nocookie.com`）だけです。
- 演習の判定コードは考え方を学ぶための簡略化したもので、実際の認証・決済の仕組みが数行で完成するわけではないことを画面に明示しています。

## ファイル構成

```
index.html
css/style.css
js/
  engine/minijs.js      制限付きの演習用インタプリタ
  engine/progress.js    進捗・解決判定・解放・保存（画面から独立した純粋な関数）
  engine/nova.js        模擬AI NOVA の定型応答
  data/registry.js      章の定義と事件の登録口
  data/cases/ch1〜6.js  30事件（講義・資料・仮説・コード・テスト・対応）
  data/videos.js        動画一覧（実在確認済みのもののみ）
  data/glossary.js      用語辞典
  data/basics.js        基礎実践の演習
  app.js                画面と操作
tests/
  run-tests.js          データ・ロジックの自動テスト（依存なし）
  e2e.js                ブラウザでの通し確認（Playwright）
```

## 事件・講義を追加するには

`js/data/cases/` にファイルを作り（または既存の章ファイルに追記し）、`HL.addCases([...])` で登録します。画面や判定ロジックの変更は不要です。各事件は少なくとも次の項目を持ちます。

`id / level / chapter / title / organization / summary / lecture / evidence / hypotheses / requiredEvidence / starterCode / testCases / responseActions / completionRules`

- `requiredEvidence` を省略すると `evidence` の `key: true` から作られます。
- `completionRules` を省略すると `responseActions` の `effect`（`good` = 必須、`bad` = 不適切）から作られます。
- `testCases` には「許可（true）」と「拒否（false）」の両方を入れてください（全部許可・全部拒否では合格しないことを自動テストで確認します）。

新しいファイルを作った場合は `index.html` の `<script>` に追加してください。

## テスト

```sh
npm test            # データ・ロジック（259件）
npm run test:e2e    # ブラウザ通し確認（Playwright と Chromium が必要）
```

`run-tests.js` が確認すること：30事件・6章×5事件・事件名と章名、各事件の講義4部構成と固有性、資料と仮説、模範解答の合格と初期コードの不合格、全部許可・全部拒否の不合格、正しい手順で解決条件がそろうこと、証拠不足・講義未完了・不適切な対応・合格後のコード変更で認定できないこと、演習環境が危険な文法を拒否すること、銀行の回収額（停止30万・返還40万・未解決50万＝120万）と凍結≠返金、防御で「新端末の全拒否」が不合格になること、レベル解放・体験モード・保存と再開・壊れたデータ・旧形式の移行・やり直し・検索、実在の URL を含まないこと。

`e2e.js` が確認すること：LEVEL 01 を画面操作だけで解決して LEVEL 02 が解放されるまでの通し操作、講義位置の保存と再読込、NOVA の模擬AI表示、やり直し、LEVEL 30 の回収額と防御シナリオ、動画・基礎実践・単語検索、全30事件×8工程の表示、スマートフォン幅（375px）で横にはみ出さないこと、JavaScript エラーがないこと。

## 動画について

`js/data/videos.js` の動画は、2026-10-12 に Web 検索のインデックスで **URL（動画ID）とタイトルの組を確認できたもの**だけを掲載しています。開発環境から youtube.com へ直接接続できなかったため、埋め込み再生の可否は未確認です。画面では埋め込みと同時に「YouTubeで開く」リンクを必ず表示しています。投稿者名は検索結果で確認できたものだけを表示し、不明なものは表示していません。
