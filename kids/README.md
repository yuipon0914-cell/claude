# ピコラボ（こども向け プログラミング＋AI 学習アプリ）

5〜8歳ごろの子どもが、ロボットの「ピコ」と一緒に **プログラミングの基本** と **AIのしくみ・付き合い方** を遊びながら学ぶ教材です。文字はひらがな中心、ボタンは指で押しやすい大きさ、🔊 で読み上げ（端末に日本語音声がある場合）。

## 起動方法

ビルド不要（HTML / CSS / JavaScript のみ、外部ライブラリなし）。

- `kids/index.html` をブラウザで直接開く、または
- `npx http-server kids` → 表示された URL を開く

公開版：https://claude.ai/artifact/XWpwM1Xhfr8URiV4d1jbuT （`node kids/scripts/build-artifact.js` で `dist/picolab.html` を生成して公開）

進捗はブラウザの `localStorage`（キー `picolab.progress`）にだけ保存されます。

## 内容

| しま | コーナー | ねらい |
|---|---|---|
| プログラミング | 👣 じゅんばん（1〜6） | 命令は上から順に実行される（順次処理）。⬆️⬇️⬅️➡️ ブロックを並べてゴールへ |
| | 🔁 くりかえし（7〜10） | 同じ命令のまとまりを短く書く（反復）。ブロック数の上限で「くりかえし」が必要になる |
| | 🐛 むしとり（11〜13） | 間違ったプログラムを実行して確かめ、直す（デバッグ）。実行中のブロックが光り、ぶつかったブロックは赤くなる |
| AI | 🧺 AIに おしえよう | くだもの／やさいを子どもが教え、AIが新しい食べ物を「どの例に似ているか」の理由つきで当てる。間違いを教え直すと賢くなる |
| | 🔮 つぎは なに？ | 並びから次を予測。AIは「次によく来たもの」を数えて答え、最後の問題ではわざと間違える |
| | 🤝 AIとの やくそく | 個人情報を入れない・大人と確かめる・自分で考える などを ⭕❌ クイズで |

ステージは順番に解放され、クリアでシール（🏅）が集まります。「おうちの かた・せんせい へ」ページに、ねらい・声かけのヒント・進み具合があります。

## しくみと安全

- アプリ内の「AI」は外部サービスではなく、考え方を見せるための小さな仕組みです（`js/engine/ai.js`：最近傍法 1-NN と、次に来たものの数え上げ）。答えの「わけ」を子どもの言葉で表示します。
- `index.html` の Content-Security-Policy で外部への通信を禁止しています（`connect-src 'none'`）。個人情報は扱いません。

## ファイル構成

```
kids/
  index.html
  css/kids.css
  js/engine/robot.js     プログラムの実行（くりかえしの展開・衝突判定・ほしの計算）
  js/engine/ai.js        こども向けAI（1-NN 分類・次の予測）
  js/engine/progress.js  進捗の保存・解放・シール
  js/data/levels.js      13ステージ（地図・使えるブロック・上限・模範解答・むしとりの初期プログラム）
  js/data/ai.js          たべもの・予測問題・やくそくクイズ
  js/app.js              画面と操作
  tests/run-tests.js     データ・ロジックの自動テスト（依存なし）
  tests/e2e.js           ブラウザでの通し確認（Playwright）
```

### ステージを追加するには

`js/data/levels.js` の `PL.LEVELS` に追記します。地図は `S`=スタート `G`=ゴール `*`=ほうせき `#`=き `.`=みち。`solution`（模範解答）は必須で、`best` はそのブロック数です。テストが次を確認します：模範解答でクリアできる・`best ≤ max`・「じゅんばん」では `best` が最短手数・「くりかえし」では繰り返しなしだとブロックが足りない・「むしとり」の初期プログラムはクリアできない。

## テスト

```sh
npm run test:kids       # データ・ロジック（69件）
npm run test:kids:e2e   # ブラウザ通し確認（Playwright と Chromium が必要）
```

`e2e.js` は、ステージ1を画面操作だけでクリアしてステージ2が開くまで、ブロック上限、くりかえしの回数変更、むしとり（赤く光る→消して直す→最初に戻す）、AIに教える→試す→教え直す→全問正解、予測でAIが最後に間違えること、やくそくカード、シール数、進捗の消去（2回押し）、未解放ステージへの直接アクセス、スマートフォン幅（375px）ではみ出さないこと、JavaScript エラーがないことを確認します。
