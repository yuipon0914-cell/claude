# KDP 出版手順書

第1〜10巻を Amazon KDP で出版するまでの手順と、登録画面に入力する内容をまとめています。

## 全体の流れ

1. **絵をそろえる**：残りの絵を Canva で作る（`docs/canva-todo.md`）
2. **絵をダウンロードする**：各巻の `books/volNN/canva-images.md` の一覧どおりの名前で保存する
3. **解像度を上げる**：見開き 5250×2625px、表紙 2625×2625px に足りなければ、Canva の「アップスケール」などで大きくしてから保存する
4. **入稿ファイルを作る**：絵を私に送るかリポジトリに入れ、`npm run build -- 巻番号 --final 1` で書き出す（私がやります）
5. **KDP アカウントを作る**：https://kdp.amazon.co.jp で、本人情報・振込先口座・税務情報（日本在住なら W-8BEN）を登録する
6. **1巻ずつ登録する**：下の「巻ごとの登録内容」をコピーして入力し、ファイルをアップロードする
7. **著者用見本を注文する**：印刷した実物で、色・文字・のど・裁ち落としを確認する
8. **出版する**：問題がなければ「出版」を押す。審査に最大72時間ほどかかります

## 出版前のチェック

- [ ] KDP の表紙計算ツールの背幅・表紙サイズと、`cover.pdf` の大きさが合っている
- [ ] KDP のプレビューで、文字や絵が切れていない
- [ ] 著者用見本で、色・文字の読みやすさ・のど（綴じ目）を確認した
- [ ] AI生成コンテンツを申告した
- [ ] Canva のプランの規約で、生成画像の商用利用（本としての販売）ができることを確認した
