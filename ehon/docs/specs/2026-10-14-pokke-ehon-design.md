# 「ポッケ」シリーズ 設計書

- 作成日：2026-10-14
- 状態：設計承認済み（この設計書の確認待ち）

## 1. 目的と成功の基準

**目的**
読み聞かせるだけで、お金の基本から投資の考え方まで身につく絵本をシリーズで作り、Amazon KDP で販売する。

**成功の基準**
- 全10巻がそろい、KDP でペーパーバックと Kindle 電子書籍として販売できる状態になること
- 各巻が、下記「4. 1冊の仕様」と「5. 内容の決まりごと」をすべて満たすこと

## 2. 前提条件

| 項目 | 決定内容 |
|---|---|
| 用途 | 販売 |
| 販売形態 | Amazon KDP のペーパーバック＋Kindle 電子書籍 |
| 絵 | 一般的な画像生成AIで作る。キャラクター固定機能を使い、人の手直しはしない |
| 読者 | 3〜5歳。大人が読み聞かせる |
| 学ぶ範囲 | 前半でお金の基本、後半で投資の考え方 |
| 出し方 | 全巻を作りきってから、順番に出す |
| シリーズ方式 | 主人公と固定キャラクターは毎巻登場し、巻ごとにゲストが1匹来る |

**しないこと**
- 具体的な金融商品・銘柄・サービスをすすめない
- 物語の中で「円」など実在の通貨を使わない（実在のお金の話は「おうちの方へ」だけで扱う）
- 文字を画像生成AIに描かせない（文字は組版で入れる）

## 3. 世界観とキャラクター

### 舞台：どんぐりの森
- この森では、ドングリがお金として使われている
- ドングリは、食べる・交換する・しまっておく・植える、のどれにも使える。前半の「お金の基本」と、後半の「植えて育てる＝投資」が、同じドングリでつながる

### 固定キャラクター（全巻に登場）
| 名前 | 動物 | 役割 | 見た目の目印 |
|---|---|---|---|
| ポッケ | 子リス | 主人公。4〜5歳くらいの気持ちで、好奇心が強く、すぐ食べたくなるし欲しくなる。名前の由来は、ほっぺにドングリをためこむ癖 | 明るい茶色の毛、大きなふわふわのしっぽ、**緑のマフラー** |
| モモばあ | おばあちゃんリス | 答えを教えず、「どうしてだと思う？」と問いかける | 詳細はキャラクター設定書で決める |

固定キャラクターは、AIで絵をそろえる負担を減らすため、この2匹だけにする。

### ゲスト（巻ごとに1匹）
その巻のテーマを体現する動物。一覧は「6. 全巻の構成」を参照。

### 物語の約束ごと
- ポッケが迷ったり失敗したりして、自分で気づく。大人が説教する話にはしない
- 損をする・失敗する場面も描くが、最後は必ず安心して終わる

## 4. 1冊の仕様

### ペーパーバック
- 判型：21.6cm×21.6cm（8.5インチ角）の正方形
- 印刷：フルカラー（KDP のプレミアムカラー）、裁ち落としあり
- 組み方：横書き・左開き（縦書き・右開きにできるかは制作の段階で確認し、可能なら再検討する）

### Kindle 電子書籍
- ペーパーバックと同じ絵とレイアウトを使う固定レイアウト形式
- 作成方法は、制作計画の段階で KDP の現行の手順を確認して決める

### ページ構成（全32ページ）
| ページ | 内容 |
|---|---|
| 1 | とびら（タイトル） |
| 2〜27 | 本文：13見開き（26ページ） |
| 28〜29 | おうちの方へ |
| 30 | シリーズの紹介（全10巻と、次の巻の案内） |
| 31〜32 | 奥付（AI画像の利用を明記）・空白 |

### 表紙
- 表・背・裏を1枚にまとめたペーパーバック用の表紙
- 背幅はページ数と用紙から KDP の計算式で自動計算する

## 5. 内容の決まりごと

### 本文
- ひらがなを基本にし、名前と音を表す言葉だけカタカナにする
- 言葉の区切りにスペースを入れる「わかち書き」にする（例：「ポッケは どんぐりを みつけました」）
- 1見開きに1〜2文、40字ほどまで
- くり返しや、声に出して楽しい言葉を入れる
- 文字は大きく、読みやすい丸い書体にする

### おうちの方へ（2ページ）
- この巻の学びを、実際のお金の言葉で説明する
- 読んだあとに子どもに聞いてみる質問を3つ載せる
- 「特定の金融商品をすすめるものではありません」と明記する

## 7. 制作の流れ

### 共通資料（最初に1回だけ作る）
1. **キャラクター設定書**：ポッケ、モモばあ、ゲスト10匹の見た目を、毎回同じ文で指示できるように固定する。表情や体の比率の決まりも含める
2. **画風ガイド**：絵のタッチ、色、光の雰囲気を、プロンプトの共通部分としてまとめる
3. **画像生成AIの試し描き**：ポッケを5場面ほど描き、絵がそろうツールを選ぶ（Midjourney と Leonardo から試す）

### 1巻ごとの作業
| 手順 | 担当 | 内容 |
|---|---|---|
| 1. 原稿 | Claude | 本文13見開き、場面ごとの絵の指示とAIへのプロンプト、おうちの方へ |
| 2. 原稿の確認 | 著者 | 読み上げて直す |
| 3. 絵の生成 | 著者 | プロンプトでAIに描かせ、画像をリポジトリに入れる |
| 4. 絵のチェック | Claude | キャラクターの見た目の目印（マフラーの色、しっぽなど）がそろっているか、チェック表で確認する |
| 5. 組版 | Claude | 絵と文字を組み合わせ、KDP 用の本文PDF・表紙PDF・Kindle 用ファイルを自動で作る |
| 6. 見本の確認 | 著者 | KDP の著者用見本を注文して、印刷した実物を確認する |
| 7. 出版 | 著者 | KDP に登録する（AI利用を申告） |

### 作業場所
このリポジトリの `ehon/` フォルダで作業する。

### KDP の規約上の注意
- AIで作った画像（人が手直ししたものや表紙も含む）は、KDP の登録時に申告する。申告していないと販売停止になることがあると報じられている
- 正式な規約の文言は、出版前に KDP の公式ヘルプで確認する

## 8. 制作計画の段階で確認すること
- KDP ペーパーバック（和書）で、縦書き・右開きが選べるか
- Kindle 用の固定レイアウト電子書籍の現行の作成手順
- 21.6cm 角・プレミアムカラー・32ページの場合の、背幅と裁ち落としの寸法
- 選んだ画像生成AIの、商用利用に関する規約
