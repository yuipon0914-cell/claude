# 試し描き用プロンプト（ツール選び）

同じキャラクター「ポッケ」を5場面描いて、どのツールがいちばん絵をそろえられるかを比べます。

## 進め方

1. 候補のツール（Midjourney と Leonardo AI）で、まず場面1を何枚か描き、気に入った1枚を「基準の絵」に決める
2. 基準の絵を、各ツールのキャラクター参照機能（Midjourney の Omni Reference、Leonardo の Character Reference）に登録する
3. 場面2〜5を、参照を付けて描く
4. 下の観点で比べ、点数の高いツールに決める
5. 決めた基準の絵は `ehon/data/reference/pokke.png` に保存しておく（以後すべての巻で参照に使う）

## 比べる観点

- [ ] 5場面とも緑のマフラーが描かれている
- [ ] 毛の色・おなかの色・しっぽの形が5場面でそろっている
- [ ] 顔立ち（目の大きさ・ほっぺ）がそろっている
- [ ] 水彩のやわらかい画風がそろっている
- [ ] 文字や変なロゴが入らない
- [ ] 商用利用できるプランと規約である（販売するので必ず確認）
