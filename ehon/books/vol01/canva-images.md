# 第1巻 Canva で作った絵

2026-10-15 に Canva の画像生成で作成しました。キャラクターの基準の絵を参考画像として渡して、見た目をそろえています。

## 保存のしかた

1. 下のリンクを開く（あなたの Canva アカウントにログインした状態で）
2. いちばん大きなサイズでダウンロードする
3. 「保存するファイル名」に名前を変えて、`ehon/books/vol01/images/` に置く
4. 印刷用に 5250×2625px（表紙は 2625×2625px）に足りなければ、アップスケールしてから置く
5. `NODE_PATH=$(npm root -g) npm run build -- 1 --final 1` で入稿用ファイルを書き出す
